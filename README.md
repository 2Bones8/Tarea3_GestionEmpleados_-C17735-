## Instrucciones de Ejecución
1. Localice la carpeta `Scripts` en la raíz del proyecto.
2. Ejecute el archivo `ScriptBD.sql` en su instancia de **SQL Server (LocalDB)**.
3. Abra la solución en Visual Studio.
4. Asegúrese de que la cadena de conexión en `appsettings.json` apunte a su servidor local.
5. Presione `F5` para iniciar la aplicación.

## Descripción
En caso de haber mas de 5 registros, se mostrará una paginación para navegar entre ellos, esto permite una mejor experiencia de usuario al manejar grandes cantidades de datos.
